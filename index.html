ℹ️ Tentang OTAKUVERSE

OTAKUVERSE v3.0 (Aniyomi Web Edition) adalah platform web anime open-source yang mereplikasi penuh arsitektur dan pengalaman Aniyomi/Tachiyomi.

Dibuat untuk ekosistem Linux (Waydroid & Native Host Browser) dengan prinsip 100% bebas iklan, zero malware, dan arsitektur scraper modular Keiyoushi.
